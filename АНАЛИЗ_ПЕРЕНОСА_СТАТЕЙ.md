## 🎯 ОБЩАЯ КОНЦЕПЦИЯ

Система работает по принципу **MVC (Model-View-Controller)**:
- **Model** - работа с базой данных
- **View** - отображение данных
- **Controller** - логика обработки запросов

## 📁 1. КОНТРОЛЛЕР ГЛАВНОЙ СТРАНИЦЫ

### Файл: `/var/www/mySimple/application/controllers/HomepageController.php`

**Что делает:**
- Загружает статьи из БД
- Загружает категории из БД
- Передает данные в представление (view)

**Ключевой код:**

```php
public function indexAction()
{
    $results = array();
    
    // 1. ЗАГРУЗКА СТАТЕЙ (первые 5 для главной страницы)
    $HOMEPAGE_NUM_ARTICLES = 5;
    $Article = new ArticleModel();
    $data = $Article->getListFiltered(
        $HOMEPAGE_NUM_ARTICLES,  // Количество статей
        null,                     // categoryId (null = все категории)
        null,                     // subcategoryId (null = все подкатегории)
        "publicationDate DESC",   // Сортировка (новые сначала)
        true                      // onlyVisible (только видимые)
    );
    $results['articles'] = $data['results'] ?? [];
    $results['totalRows'] = $data['totalRows'] ?? 0;
    
    // 2. ЗАГРУЗКА КАТЕГОРИЙ
    $Category = new CategoryModel();
    $categoryData = $Category->getList();
    $results['categories'] = array();
    if (isset($categoryData['results']) && is_array($categoryData['results'])) {
        foreach ($categoryData['results'] as $category) {
            $results['categories'][$category->id] = $category; // Индексируем по ID
        }
    }
    
    // 3. ПЕРЕДАЧА ДАННЫХ В ПРЕДСТАВЛЕНИЕ
    $this->view->addVar('results', $results);
    $this->view->render('homepage/index.php');
}
```

**Важные моменты:**
- ✅ Использует `getListFiltered()` для получения статей
- ✅ Загружает категории и индексирует их по ID для быстрого доступа
- ✅ Устанавливает layout `cms-main.php` для единого стиля
- ✅ Доступ открыт для всех (`'roles' => ['?', '@']`)

## 📁 4. ПРЕДСТАВЛЕНИЕ ГЛАВНОЙ СТРАНИЦЫ (View)

### Файл: `/var/www/mySimple/application/views/homepage/index.php`

**Что отображает:**
- Список статей с датами
- Названия категорий под каждой статьей
- Подкатегории (если есть)
- Благодарности (если есть)
- Полный текст статьи

**Ключевой код:**

```php
<?php foreach ($results['articles'] as $article) { ?>
    <li class='article-<?php echo $article->id?>'>

            <!-- ЗАГОЛОВОК СТАТЬИ (ссылка на полную статью) -->
            <a href="<?= WebRouter::link("article/view&articleId=" . $article->id)?>">
                <?php echo htmlspecialchars($article->title ?? '')?>
            </a>
            
            <!-- КАТЕГОРИЯ -->
            <?php if (isset($article->categoryId) && isset($results['categories'][$article->categoryId])) { ?>
                <span class="category">

                        <?php echo htmlspecialchars($results['categories'][$article->categoryId]->name ?? '')?>

                <span class="category">Без категории</span>
            <?php } ?>
            
            <!-- ПОДКАТЕГОРИЯ (если есть) -->
            <?php if (isset($article->subcategory_id) && $article->subcategory_id) { ?>
                <?php 
                $subcategory = $Subcategory->getById($article->subcategory_id);
                if ($subcategory) { ?>
                    <span class="subcategory">
                        | 
                        <a href="<?= WebRouter::link("subcategory/archive&subcategoryId=" . $article->subcategory_id)?>">
                            <?php echo htmlspecialchars($subcategory->name ?? '')?>
                        </a>
                    </span>
                <?php } ?>
            <?php } ?>
        </h2>
        
        <!-- БЛАГОДАРНОСТИ -->
        <?php if (!empty($thanksNames)) { ?>
            <div class="article-thanks">
                <strong>Благодарности:</strong> <?php echo implode('| ', $thanksNames) ?>
```

## 📁 5. КОНТРОЛЛЕР КАТЕГОРИЙ (CategoryController)

### Файл: `/var/www/mySimple/application/controllers/CategoryController.php`

**Что делает:**
- Показывает все статьи определенной категории
- Использует тот же метод `getListFiltered()`, но с фильтром по `categoryId`

**Ключевой код:**

```php
public function archiveAction()
{
    $categoryId = isset($_GET['categoryId']) ? (int)$_GET['categoryId'] : null;
    
    // Получаем статьи ТОЛЬКО этой категории
    $Article = new ArticleModel();
    $data = $Article->getListFiltered(
        1000000,        // Все статьи
        $categoryId,    // Фильтр по категории
        null,           // Без фильтра по подкатегории
        "publicationDate DESC",
        true
    );
    $results['articles'] = $data['results'];
    
    // Получаем текущую категорию для заголовка
    $results['category'] = $Category->getById($categoryId);
}
```

**Разница с главной страницей:**
- Главная: `getListFiltered(5, null, null, ...)` - 5 статей, все категории
- Категория: `getListFiltered(1000000, $categoryId, null, ...)` - все статьи, одна категория

### 1. Пользователь заходит на главную страницу
```
http://mysimple.loc/index.php?route=homepage/index
```

### 2. SimpleMVC вызывает HomepageController->indexAction()
```php
HomepageController::indexAction()
```

### 3. Контроллер загружает данные
```php
// Статьи
$Article = new ArticleModel();
$data = $Article->getListFiltered(5, null, null, "publicationDate DESC", true);

// Категории
$Category = new CategoryModel();
$categoryData = $Category->getList();
```

### 4. ArticleModel выполняет SQL-запрос
```sql
SELECT id, categoryId, subcategory_id, title, summary, content, 
       is_visible, UNIX_TIMESTAMP(publicationDate) AS publicationDate 
FROM articles 
WHERE is_visible = 1 
ORDER BY publicationDate DESC 
LIMIT 5
```

### 5. Данные передаются в представление
```php
$this->view->addVar('results', $results);
$this->view->render('homepage/index.php');
```

### 6. View отображает статьи
```php
foreach ($results['articles'] as $article) {
    // Отображение статьи
    // Использование $results['categories'][$article->categoryId] для названия категории
}
```

### 7. Layout оборачивает всё в HTML

## ✅ КЛЮЧЕВЫЕ ОСОБЕННОСТИ РЕАЛИЗАЦИИ

1. **Единый метод получения статей**
   - `getListFiltered()` используется везде (главная, категории, подкатегории)
   - Разные параметры = разные результаты

2. **Индексация категорий по ID**
   - `$results['categories'][$category->id] = $category`
   - Быстрый доступ: `$results['categories'][$article->categoryId]`

3. **Безопасность**
   - `htmlspecialchars()` для защиты от XSS
   - Подготовленные запросы (PDO) для защиты от SQL-инъекций
   - Проверки на существование данных (`isset()`, `??`)

4. **Гибкость**
   - Фильтрация по категории/подкатегории
   - Сортировка
   - Ограничение количества статей

5. **Единый стиль**
   - Один layout (`cms-main.php`) для всех публичных страниц
   - Один CSS файл (`cms-style.css`)
