📍 РАСПОЛОЖЕНИЕ ГЛАВНОЙ СТРАНИЦЫ И СТИЛЕЙ

═══════════════════════════════════════════════════════════════

1. СТИЛИ ДЛЯ ГЛАВНОЙ СТРАНИЦЫ:
   
   📁 Файл: /var/www/mySimple/web/CSS/cms-style.css
   
   Это основной файл стилей, который содержит:
   - Стили для body (голубой фон #00a0b0)
   - Стили для контейнера (#container)
   - Стили для логотипа (#logo)
   - Стили для списка статей (#headlines)
   - Стили для заголовков, категорий, футера
   
   Подключается в layout через:
   <link rel="stylesheet" type="text/css" href="/CSS/cms-style.css" />

═══════════════════════════════════════════════════════════════

2. ГЛАВНАЯ СТРАНИЦА (HTML разметка):
   
   📁 Файл: /var/www/mySimple/application/views/homepage/index.php
   
   Это представление (view) главной страницы.
   Содержит HTML код для отображения списка статей:
   - Список статей (<ul id="headlines">)
   - Заголовки статей
   - Категории и подкатегории
   - Благодарности
   - Содержание статей

═══════════════════════════════════════════════════════════════

3. КОНТРОЛЛЕР ГЛАВНОЙ СТРАНИЦЫ (логика):
   
   📁 Файл: /var/www/mySimple/application/controllers/HomepageController.php
   
   Это контроллер, который:
   - Загружает статьи из БД (первые 5)
   - Загружает категории
   - Передает данные в представление
   - Указывает какой layout использовать

═══════════════════════════════════════════════════════════════

4. LAYOUT (обертка страницы):
   
   📁 Файл: /var/www/mySimple/application/views/layouts/cms-main.php
   
   Это макет страницы, который:
   - Подключает CSS файл (строка 20)
   - Содержит структуру HTML (head, body, container)
   - Включает логотип
   - Включает футер
   - Вставляет содержимое главной страницы через <?= $CONTENT_DATA ?>

═══════════════════════════════════════════════════════════════

КАК ЭТО ВСЕ РАБОТАЕТ ВМЕСТЕ:

1. Пользователь заходит на главную страницу
   ↓
2. SimpleMVC вызывает HomepageController->indexAction()
   ↓
3. Контроллер загружает статьи из БД и передает в представление
   ↓
4. SimpleMVC использует layout 'cms-main.php'
   ↓
5. Layout подключает CSS файл /CSS/cms-style.css
   ↓
6. Layout вставляет содержимое из homepage/index.php в $CONTENT_DATA
   ↓
7. Пользователь видит стилизованную главную страницу

═══════════════════════════════════════════════════════════════

ПУТИ К ФАЙЛАМ:

Стили:        /var/www/mySimple/web/CSS/cms-style.css
Представление: /var/www/mySimple/application/views/homepage/index.php
Контроллер:   /var/www/mySimple/application/controllers/HomepageController.php
Layout:       /var/www/mySimple/application/views/layouts/cms-main.php
