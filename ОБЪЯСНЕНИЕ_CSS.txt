1. СТИЛИ ДЛЯ ФУТЕРА (СТИКИ-ФУТЕР)
───────────────────────────────────────────────────────────────

html {
  position: relative;
  min-height: 100%;
}
→ Делает HTML контейнером для позиционирования
→ min-height: 100% - минимальная высота = высота экрана

body {
  margin-bottom: 60px;
}
→ Отступ снизу для body = 60px (чтобы контент не перекрывался футером)

.footer {
  position: absolute;    → Футер прикреплен к низу страницы
  bottom: 0;            → Прижат к самому низу
  width: 100%;          → На всю ширину экрана
  height: 60px;        → Высота футера = 60px
  line-height: 60px;    → Вертикальное выравнивание текста по центру
  background-color: #f5f5f5;  → Светло-серый фон
}

ЗАЧЕМ ЭТО НУЖНО:
Это "sticky footer" - футер всегда внизу страницы, даже если контента мало.
Если контента много, футер идет после контента.

2. КЛАСС .copyleft (КОПИЛЕФТ)
───────────────────────────────────────────────────────────────

.copyleft {
    -webkit-transform: scaleX(-1);  → Для браузера Safari/Chrome
    -moz-transform: scaleX(-1);     → Для Firefox
    -o-transform: scaleX(-1);       → Для Opera (старые версии)
    -khtml-transform: scaleX(-1);   → Для Konqueror
    -ms-transform: scaleX(-1);       → Для Internet Explorer
    transform: scaleX(-1);           → Стандартный CSS
    display: inline-block;
}

ЧТО ДЕЛАЕТ:
Отражает символ по горизонтали (зеркалит).

ПРИМЕР:
Обычный символ:  ©
С классом .copyleft:  ⓒ (отраженный)

ЗАЧЕМ ЭТО:
Это шутка/игра слов:
- "copyright" (копирайт) → "copyleft" (копилефт)
- Вместо обычного © показывают отраженный символ

ГДЕ ИСПОЛЬЗУЕТСЯ:
В футере SimpleMVC:
<span class="copyleft">&copy;</span>

═══════════════════════════════════════════════════════════════

3. КЛАСС .footer-link (ССЫЛКИ В ФУТЕРЕ)
───────────────────────────────────────────────────────────────

.footer-link {
    color: #17a2b8;
}

ЧТО ДЕЛАЕТ:
Устанавливает цвет ссылок в футере = голубой (#17a2b8)

ПРИМЕР:
<a href="..." class="footer-link">ссылка</a>
→ Ссылка будет голубого цвета

═══════════════════════════════════════════════════════════════

ИТОГО:
───────────────────────────────────────────────────────────────

1. Стили для футера - делают его "прилипшим" к низу страницы
2. .copyleft - отражает символ © для шутки
3. .footer-link - голубой цвет для ссылок в футере

Эти стили используются в админ-панели SimpleMVC (admin-main.php layout)
