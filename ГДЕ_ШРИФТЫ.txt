═══════════════════════════════════════════════════════════════
КАК ИЗМЕНИТЬ ШРИФТЫ:
═══════════════════════════════════════════════════════════════

1. Откройте файл: /var/www/mySimple/web/CSS/cms-style.css

2. Найдите строку 7:
   font-family: "Trebuchet MS", Arial, Helvetica, sans-serif;

3. Замените на нужный шрифт, например:
   font-family: "Arial", sans-serif;
   или
   font-family: "Georgia", serif;
   или
   font-family: "Times New Roman", serif;

4. Сохраните файл и обновите страницу в браузере

═══════════════════════════════════════════════════════════════
ПРИМЕРЫ ИЗМЕНЕНИЯ ШРИФТОВ:
═══════════════════════════════════════════════════════════════

Для основного текста (body):
font-family: "Arial", sans-serif;

Для заголовков (h1, h2):
Можно добавить в CSS:
h1, h2 {
  font-family: "Georgia", serif;
}

Для статей:
Можно добавить:
.article-content {
  font-family: "Times New Roman", serif;
  font-size: 16px;
}
